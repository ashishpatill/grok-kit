The project script is the ACI (agent-computer interface). The model fills in judgment; it does not reorder phases.

Copy `templates/_shared/verify/verify.sh` to `.cursor/verify/verify.sh` and replace `drive()`.

`feature-map.json` names extra surfaces only when the repo truly has more than one prove-it path (CLI vs web). Default is one surface.

Logs: `.cursor/verify/last.json` and `last.log` (gitignored).
